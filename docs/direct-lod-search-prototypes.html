Start with option 01.

A single field removes the question of where to search. Show local matches immediately, then add clearly labelled LOD results. Saving should update the same entry everywhere, even when the query is a French, German, or Portuguese translation.

Option 02 is the safer alternative if keeping dictionary requests explicit matters more than eliminating a switch.
