What changes

Fix the frame, then the details.

Keep the existing Blue Night identity. Fix layout ownership before adding decoration.

01

The popup stops changing size

A bounded 420 × 600px shell. Only content scrolls. A reserved scrollbar gutter prevents the sideways nudge between short and long results.

Found: the missing CSS comment opener invalidates the body sizing rule. Test content width changes by 15px between sources.

02

Search stays where you put it

Source, input and language/count row stay above the scroller. Current-page details move below search and stay available in both sources.

Found: Search LOD hides current-word actions and notes. In Chrome, search jumps upward by about 135px.

03

One word, one set of actions

Favorite and Study use the same independent controls everywhere. No oversized Save button, duplicate membership actions or ambiguous saved state. Notes and examples share one disclosure.

Found: 17px saved headings vs 24px lookup headings, “Fav” vs “Favorite”, and different save controls for the same word.

04

Counts cannot squeeze the input

Counts sit below a full-width search field. Loading, no matches and offline states share the results area. Errors offer Retry or a return to local words.

Found: the live count shares a flex row with search. A filtered count reduced the input width by about 42px.

05

Keyboard and feedback get a contract

Arrow keys switch tabs and sources, with one tab stop per group. Queries, notes and open details survive source changes. A reserved status row keeps Undo separate from the last word.

Found: tab/radio roles without arrow-key handling. Feedback and Undo also use the same fixed-bottom position.

06

Companion pages fit narrow windows

Page title and actions wrap deliberately. Flashcard grading uses three equal columns. Vault filters remain in the normal flow, without a hard-coded header-height subtraction.

Found: Flashcards content reaches 409px in a 375px viewport. Vault's 179px wrapped header disagrees with its 116px iframe offset.
