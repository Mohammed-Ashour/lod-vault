2. Identified Issues

No unified button sizing system

High

There are 5 distinct font sizes (9, 11, 12, 13, 15px) and 8 distinct vertical paddings across interactive elements. The popup alone has 4 different button heights. This creates visual discordance when sections sit side-by-side and makes the UI feel cobbled together rather than designed.

✅ Fix: Adopt a 3-tier sizing system:

  • Compact — padding: 4px 10px; font-size: 12px → ~26px height. Used for pills, chips, inline toggles.
  • Standard — padding: 6px 14px; font-size: 12px → ~30px height. Used for all primary action buttons.
  • Touch — padding: 8px 16px; font-size: 13px → ~34px height. Used only for large touch-targets (card flip, nav).

Content banner buttons too small

High

The Favorite/Study buttons embedded in lod.lu pages use padding: 3px 8px; font-size: 11px; border-radius: 5px. At ~23px height, they're below the 24px minimum touch target recommended by WCAG and feel cramped compared to the rest of the page. The targeted language ("★ Favorited" / "✓ Study") also runs long in active state.

✅ Fix: Increase to padding: 4px 10px; font-size: 12px; border-radius: 6px. Shorten active labels: "★ Fav" / "✓ Study" (already partially done — verify consistency).

Flashcards rating buttons oversized

Medium

Hard/Good/Easy buttons use padding: 10px 12px; font-size: 13px; border-radius: 10px, giving ~36px height. They consume a disproportionate share of vertical space on the card view. Despite being "action" buttons, they don't need more than 30px to be comfortable.

✅ Fix: Change to padding: 8px 10px; font-size: 12px; border-radius: 6px. Saves 6px per button row and keeps them clearly tappable on mobile.

Popup header buttons inconsistent sizing

Medium

.btn-ghost (Flashcards, Vault) uses padding: 5px 10px; font-size: 12px, while .btn-ghost.btn-secondary (HTML, Anki) shrinks to font-size: 11px. They sit in the same row with a visual separator, but the secondary ones look diminutive.

✅ Fix: Unify both to padding: 5px 12px; font-size: 12px. The secondary vs primary distinction shifts to color and opacity only, not size.

Saved-list toggle pills too small for touch

Medium

List-item toggle pills use padding: 2px 7px; font-size: 11px → ~23px height. This is below the WCAG 24px minimum touch target, and the pill is even harder to hit because it's inline.

✅ Fix: Increase to padding: 3px 8px; font-size: 11px → ~24px height. Matches the current "compact" pill size but slightly more relaxed horizontally.

Audio button size differs between popup and flashcards

Medium

.audio-btn is 26×26 in the popup but 28×28 in flashcards — a 2px difference that's visible when switching views. The SVG icon is also 13px vs 14px.

✅ Fix: Standardize to 26×26px everywhere with 13×13px icons. The 26px size is enough for touch and visually consistent with other compact controls.

Mixed border-radius values

Low

Rectangular buttons use border-radius: 5px (hardcoded in content banner), 6px (--r-sm), and 10px (--r-md). The banner hardcodes 5px while the rest of the extension uses var(--r-sm) = 6px.

✅ Fix: Use var(--r-sm) (6px) for all rectangular buttons and var(--r-full) (999px) only for pills/chips across all views.

Font-weight inconsistency on similar buttons

Low

.btn-ghost, .btn-tool, .btn-link, .auto-toggle use font-weight: 600, but .secondary-button, .toggle-pill, rating buttons, and banner buttons use font-weight: 700. This makes buttons look subtly thinner or bolder depending on the view.

✅ Fix: Standardize to font-weight: 700 for all standalone action buttons. Use 600 only for very small inline elements (chips, meta links).

Flashcard nav/control area wastes vertical space

Low

The flashcard header uses padding: 12px 16px per side (24px vertical total) plus controls in a flex-wrap row with gap: 8px. The controls include 3 selects and 2 buttons, which could be more compact. The select padding (7px vertical) makes them taller than the buttons.

✅ Fix: Reduce header padding to 10px 14px. Reduce select padding to 6px 28px 6px 10px. Increase header gap to 10px for better spacing. This saves ~8px without hurting readability.

6. Cross-view consistency rules

  • Font-weight 700 for all interactive labels (buttons, pills, selects). Use 600 only for meta-text.
  • Border-radius 6px for all rectangles. No more 999px pill shapes on action buttons — pills are now rectangular with 6px radius everywhere (popup, flashcards, lens overlay, content banner).
  • Audio buttons 26×26px everywhere, with 13×13px SVG icons.
  • Font-size 12px for all action buttons and selects. 11px only inside compact list items.
  • Standard button height ≈ 28-30px. Toll buttons (320px-wide popup) should all hit this target.
  • Expand/Collapse merged into a single toggle button (#5) that toggles aria-pressed state, icon (⊞/⊟), and label text.
